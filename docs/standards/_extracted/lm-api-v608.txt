1  通用约定
1.1  数据格式
1.1.1  标准请求格式
URL：
https://{device_ip}/api/{api_name}?{query_string}
参数说明：
参数说明{device_ip}设备ip或对应host名称{api_name}接口路径，其中{task_id}代表任务号{query_string}由全局参数部分和具体API调用参数部分组成；对于POST请求，{query_string}应该放在POST参数中传递全局参数：
字段名类型备注是否必须usernameString登录用户名：使用http参数认证时需要NpasswordString登录密码：使用http参数认证时需要NformatString返回值类型：json,xml（默认为json）N编码：
请求参数，返回内容统一采用utf8编码


1.1.2  标准返回格式
json{
"ret_code": 0,
"ret_msg": "success",
"data": object
}　　
xml<?xml version="1.0" encoding="utf-8"?>
<aurora>
<ret_code>0</ret_code>
<ret_msg>success</ret_msg>
<data>
<object></object>
</data>
</aurora>HTTP返回码说明
HTTP STATUS CODE说明200系统标准响应401未认证，或者认证失败403未授权使用404无此接口405方法不被允许1.2  认证
1.2.1  UsernamePassword认证
通过url参数形式传输用户密码
1.2.2  Basic认证
Request header
Authorization: Basic base64_encode(username+password)
1.2.3  认证过程
首先判断url里是否有用户名和密码两个参数，如果都有开始UsernamePassword认证，失败返回http401，url没有这两个参数，向客户端发起basic认证请求，客户端再次请求需要带上basic认证相关参数，再进行认证，失败返回http401。

2.1.1  创建任务
URL：/api/task/create
RSAS版本：V6.0R02F00
请求方式：POST
请求参数：
字段名类型备注是否必须typeuint1,2,3,4,8 默认为1
1:漏洞扫描任务（v）
2:配置核查任务（b）
3:系统评估任务 + 配置核查任务（v+b）
4:口令猜测任务（pwd）
8:web应用扫描任务
说明：指定任务类型的目的是为了验证xml的合法性Yconfig_xmlfile任务配置xml: 对应任务类型的xml参考附录Y说明：
通过xml文件创建任务可以指定详细的任务配置，下边还有4个对应单类型任务接口，用于创建简单配置的任务。xml中的targets的ip配置格式请参考单独漏扫的格式。
注意：
任务配置xml中的targets的IP数限制最大1个B（65535）。在web扫描的targets配置中url的限制为5个。
