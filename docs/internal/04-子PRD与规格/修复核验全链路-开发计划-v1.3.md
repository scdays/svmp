## 2. 目标与验收（v1.3）

**总目标**：在 v1.4 门闸编排已落地基础上，完成**联调验收**、**离线处置闭环**，并按 §7.5 将任务详情工作台落地到 `TaskDrawer.vue`。

**Wave 验收标准**：

| Wave | 验收 |
|------|------|
| **A 联调** | TC-01～TC-14 通过；§18 单测绿；Gate→Scan 级联可演示；台账 9+10 成对 |
| **B 离线闭环** | 子任务/主任务 recycle（reportType 3/10/32）→ 分层判定 6/7/10 → submit 可回传 |
| **F-W2 工作台** | 列表行内摘要、任务全页四标签、子任务卡片+全页、结果摘要 Tab、去处置弹窗与 ProMethodDrawer 行为一致 |
| **Review** | 对照 PRD §9 / §7.5 / §18；`mvn test` + 前端 lint |

**不改什么**（延续 v1.2）：

- `open-api-service`、Partner `verify-fix` 契约、无关子应用
- 不推倒 P0 台账骨架 / confirmToken / Merger

### 3.1 F-W2 前端落地清单（§7.5）

对照原型与 PRD §7.5，Vue 实现至少包含：

1. **主任务列表**：点击行 → 行内嵌入摘要（可收起）；操作列 详情/结果/台账
2. **任务全页**：顶栏返回 + 主任务摘要 + 四标签（概览 / 子任务 / 下发详情 / 结果摘要）
3. **子任务 Tab**：纵向卡片（波次、策略、手段、meta）；操作：详情/追踪/结果/台账/去处置
4. **子任务全页**：无右栏；全宽 Tab；结果/台账入口仅两 Tab
5. **结果摘要**：Tab 切换任务结果 \| 台账日志（与子任务全页同构）
6. **处置弹窗**：复用 `ProMethodDrawer`；子任务 `taskType=subTask`

**建议改文件**：

- `TaskDrawer.vue`（主框架、列表、全页模式）
- `TaskInfoDrawer.vue` / 子任务上下文（已有，按需 pageMode 扩展）
- `ProMethodDrawer.vue`（处置弹窗，已有）
