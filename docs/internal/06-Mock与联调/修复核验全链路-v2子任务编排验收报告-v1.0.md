## 4. 配置说明

```yaml
# application.yml
compliance:
  verify-fix:
    dispatch-mode: sequential   # 默认；改为 parallel 可同时下发两类子任务
```

回收与报告解析顺序**不受** `dispatch-mode` 影响：始终先连通性检测、后修复核验。
