Partner 主动发起；平台提取 vulInfoID → 系统漏洞库资产 IP → 最近 scanner_vendor → task-center 全量扫描（不支持指定产品漏洞）→ 回收后仅判定目标漏洞状态。
端到端时序
Partner POST /instances/{vulInfoID}/verify-fix (stat=5) -> open-api INSTANCE_VERIFY_FIX + 幂等 -> vul-pass: vul_archive_inst.assetIp + 最近 sub.scanner_vendor -> vuln-task-center: SINGLE 全量 survey (非 SOC_DUAL) -> Kafka 回收全量结果 -> 仅匹配目标 vulInfoID: 未检出->6 | 仍检出->7 | 失败->10 -> Webhook INSTANCE_VERIFY_FIX_COMPLETED + EXPORT_READY(VERIFY_FIX_SCAN)
