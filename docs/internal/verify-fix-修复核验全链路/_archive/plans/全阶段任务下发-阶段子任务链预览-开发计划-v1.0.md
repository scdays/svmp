## 开发计划（已确认执行）

**目标**：按原型落地三菜单共用的「阶段子任务链预览」：全阶段预览表、1026 双厂家、跨级资产切批；核验零回归。

**验收标准**（总览，细则见方案 §6 AC）：

- [ ] 产品预警：1080 只读单步预览，无设备/无切批，可下发  
- [ ] 系统工单：0～4 阶段预览正确；1026 强制双厂家；无切批区  
- [ ] 跨级：切批开关 + 每批资产数；预览按批展开；1026×切批行数正确  
- [ ] 阶段 4：`confirmToken` / 设备锁定 / 禁止未匹配确认 — 与现网一致  
- [ ] `pre/dispatch` 返回 `previewRows`（及 dualVendor/batchSummary）；Domain 构建、App 不堆编排  
- [ ] 编译/单测/前端 lint + 分层 Review 通过  

**不改什么**：

- `open-api-service`、Partner、recycle 内核、BPM  
- 不把 AutoDispose 会话塞进下发抽屉  
- 不为三菜单复制三套预览页  
- 未要求前不 commit / push  

| Wave | Agent | 改什么 | 交付物 |
|------|-------|--------|--------|
| **W1** | 后端-Domain | `PhaseDispatchPreviewBuilder`；`DualVendorScannerGuard`；`AssetBatchSplitter`；扩展 preDispatch 领域预览 | Domain API + 单测（0～4、1026、切批） |
| **W2** | 后端-App/Ui | `VulTaskDispatchDTO` / 出参 DTO；`preDispatch` 组参；1026/切批入参校验透传 | 接口可联调 |

| **W4** | 前端-抽屉 | `AddTaskDrawer`/`BaseInfo`/`SafeSourceDriver`：双厂家选、跨级切批面板、确认闸门 | 对齐原型交互 |
