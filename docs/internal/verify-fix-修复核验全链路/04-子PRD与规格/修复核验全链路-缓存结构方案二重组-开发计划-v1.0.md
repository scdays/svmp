## 4. 风险与回滚

| 风险 | 缓解 | 回滚 |
|------|------|------|
| 结构大改导致在途缓存失效 | schemaVersion=2 版本校验拒绝 v1，提示重新预览（30min 自然过期） | 可接受，无需回滚 |
| 序列化兼容（hutool） | 新块类 @Data Serializable；round-trip 测试 | 回滚 T1 结构 |
| 计数直读与 scope 物化不一致 | counts 预览期与 scope 同源算；S1 校验保引用一致；单测交叉校验 | 回滚 T3（恢复重算） |
| D-1 DDL 不可逆 | groovy 增列（可空，向后兼容） | 列保留空，回滚 DO 字段 |
| 前端分数展示数据不全 | T4 确保 mainTask + subTask counts 都进 VO | 回滚 T6（恢复 targetScale） |
| 既有测试大面积失效 | T7.4 逐个更新；目标测试绿 + 全量无新增红 | 保留既有测试断言，逐步迁移 |
