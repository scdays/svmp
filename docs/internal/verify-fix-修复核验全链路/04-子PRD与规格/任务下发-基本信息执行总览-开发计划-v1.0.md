## 3. T1 组件设计 `TaskExecutionOverview.vue`

- **props**：`baseInfo`(Object)、`procMethod`(Number)、`tskPhase`(Number)、`proMethodData`(Array)、`orderPhaseEnumData`(Array)、`orderType`(Array)
- **components**：`SetName`（处置方式/工单类型 复用，避免编码重复、与既有 UI 一致）
- **模块常量**：`CHAIN_DESC`（`code->desc`，7 项）
- **computed**：
  - `lifecycleSteps`：`baseInfo.lifecycleSteps || []`
  - `orderTypeLabel`：按 `baseInfo.orderId` 首位（1=工单类型，2=任务类型）
  - `tskPhaseName` / `tskPhaseLabel`：反查枚举；`tskPhaseLabel` 去括号及内容
  - `stats`：5 项 `[{label,val}]`，无效值 -> `-`
  - `isPreview`：所有步骤 `status` 为空或 `PENDING`
  - `displaySteps`：`lifecycleSteps` 映射加 `displayStatus`（预览首步 `current`、余 `pending`；否则按 `status` 映射）
  - `pipeline`：按 `kind` 分组 `{head, core, tail}`（MAIN 首段 / CHAIN / MAIN 末段）
  - `pipeSegments`：扁平化渲染段（`card`/`arrow`/`core`），便于 `v-for`
  - `summary`：`core` CHAIN `desc` 以"；"拼接
- **methods**：`dotColor(st)` / `labelColor(st)`（状态->色）
- **模板**：标题条 -> 标签行 -> 5 统计格 -> 管线（`pipeSegments` v-for：箭头/主卡/核心编排块）-> 说明条
- **样式**：scoped less，Ant Design 配色（`#1890ff`/`#52c41a`/`#722ed1`/`#faad14`）

## 4. T2 集成 `BaseInfo.vue`

- `import TaskExecutionOverview from './TaskExecutionOverview.vue'` + `components` 注册
- `data` 增 `watchProcMethod: ''`（处置方式 reactive 代理）

- `changeprocMethod(value)` 内：`this.watchProcMethod = value`
- 模板：`a-spin` 内、`a-form` 之前插入

  ```html
  />
  ```

## 5. 数据流

```
用户改处置方式/业务阶段

  -> getData() -> baseInfo = {...data}（含 lifecycleSteps + 统计）
  -> TaskExecutionOverview props 更新 -> 管线/统计重渲染
```
