# 漏扫任务事件接口文档

> 服务名称：`vuln-task-center`  
> 默认端口：`18087`  
> 文档版本：2026-06-17  
> 源码位置：`com.mvtech.vuln.task.ui.event`

---

## 一、服务地址说明

| 访问方式 | 基础地址 |
|---------|---------|
| 直连服务 | `http://{host}:18087` |
| 网关访问（示例） | `http://172.16.4.192:7000/vuln-task-center` |

下文接口路径均相对于上述基础地址，完整 URL = 基础地址 + 接口路径。

**Content-Type：**

- GET 查询类接口：无 Body，参数通过 Query 传递
- POST 创建类接口：`application/json`

**统一响应说明（`Result` 类型）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| success | boolean | 是否成功 |
| message | string | 提示信息 |
| data | object | 业务数据（成功时返回） |

## 二、ScanTaskSurveyEvent — 漏扫任务实例接口

**Controller：** `ScanTaskSurveyEvent`  
**基础路径：** `/event/scan/task/survey`  
**说明：** 根据计划实例 ID（`surveyId`）查询扫描结果、成功/失败 IP、端口信息等。

### 2.1 查询漏洞扫描结果（分页）

**方法名：** `queryVulnScanResultBySurveyId`

| 项目 | 内容 |
|------|------|
| 请求方式 | `GET` |
| 接口路径 | `/event/scan/task/survey/query/vulnScanResult` |
| 完整 URL 示例 | `http://{host}:18087/event/scan/task/survey/query/vulnScanResult?surveyId=2041810068740395010&current=1` |

#### 请求参数（Query）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| surveyId | string | 是 | 计划实例 ID |
| current | string | 是 | 当前页码，从 1 开始；每页固定 50 条 |

| pages | long | 总页数 |
| vulnScanResultList | array | 漏洞扫描结果列表（来自 ES） |

## 三、ScanTaskEvent — SOC 创建扫描计划

### 3.1 SOC 创建扫描计划

**方法名：** `outsideSocScan`

| 项目 | 内容 |
|------|------|
| 请求方式 | `POST` |
| 接口路径 | `/event/scan/task/outside/soc/scan` |
| 完整 URL 示例 | `http://{host}:18087/event/scan/task/outside/soc/scan` |
| 说明 | 广州 SOC 需求；创建内置扫描计划，页面不可见，创建后自动注册到调度系统（mint） |

#### 请求参数（Body JSON）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| taskId | string | 是 | SOC 侧任务 ID（用于关联，会写入 remarks） |
| taskName | string | 是 | 计划名称 |
| inputIp | string | 是 | 扫描 IP，多个用英文逗号分隔，如 `1.1.1.1,2.2.2.2` |
| taskType | string | 是 | 任务类型，见下表 |
| scannerType | string | 是 | 扫描器厂商类型，见下表 |

**taskType 取值：**

| 值 | 说明 |
|----|------|
| vuln | 漏洞扫描 |
| port | 端口扫描（目前仅绿盟支持） |
| alive | 资产存活探测（目前仅绿盟支持） |

**scannerType 取值：**

| 值 | 厂商 |
|----|------|
| 1 | 绿盟 |
| 2 | 安恒 |
| 3 | 启明 |
| 4 | 天融信 |
| 7 | Nessus |
| 8 | 安智 |
| 9 | 加特林 |

#### 系统自动补充的字段

接口收到请求后，服务端会自动追加以下字段，**调用方无需传递**：

| 字段 | 自动赋值 | 说明 |
|------|---------|------|
| builtInTask | `"1"` | 内置计划，不在任务列表展示 |
| createUser | `"admin"` | 创建人 |
| remarks | `"SOC" + taskId` | 备注，用于与 SOC 任务关联 |
| scannerId | 根据 scannerType 查询 | 按厂商分类 ID 查找对应节点下扫描器 ID（多个以逗号分隔） |

#### 请求示例

```json
{
  "taskId": "SOC-20260617-001",
  "taskName": "SOC漏洞扫描计划_测试",
  "inputIp": "1.1.1.1,2.2.2.2",
  "taskType": "vuln",
  "scannerType": "1"
}
```

#### 响应参数（`Result`）

| 字段 | 类型 | 说明 |
|------|------|------|
| success | boolean | 是否创建成功 |
| message | string | 提示信息 |
| data | object | 调度系统（mint）返回的任务信息 |

**创建成功流程：**

1. 将请求参数转换为 `ScanTaskDTO` 并保存到数据库
2. 调用 mint 调度系统注册定时/立即执行任务
3. mint 注册失败时，自动回滚删除已创建的扫描计划

#### 响应示例（成功）

```json
{
  "success": true,
  "message": "操作成功",
  "data": {
    "id": "2067063951154696194",
    "taskName": "SOC漏洞扫描计划_测试",
    "taskType": "vuln",
    "appHost": "vuln-task-center",
    "path": "/event/scan/task/execute"
  }
}
```

#### 响应示例（失败）

```json
{
  "success": false,
  "message": "操作失败",
  "data": null
}
```

#### 调用示例（curl）

```bash
curl -X POST "http://{host}:18087/event/scan/task/outside/soc/scan" \
  -H "Content-Type: application/json" \
  -d '{
    "taskId": "SOC-20260617-001",
    "taskName": "SOC漏洞扫描计划_测试",
    "inputIp": "1.1.1.1,2.2.2.2",
    "taskType": "vuln",
    "scannerType": "1"
  }'
```

#### 网关调用示例


## 五、注意事项

1. **surveyId 获取方式**：SOC 创建计划成功后，需通过任务执行回调或查询计划实例列表获取 `surveyId`，再用于查询扫描结果。
2. **分页参数**：`queryVulnScanResultBySurveyId` 的 `current` 为页码（非偏移量），每页固定 50 条。
3. **IP 格式**：`inputIp` 多个 IP 使用英文逗号分隔；换行符会在服务端自动转换为逗号。
4. **内置计划**：`outsideSocScan` 创建的计划 `builtInTask=1`，不在前端任务列表中展示。
5. **扫描器匹配**：`scannerType` 会按厂商分类查找所有匹配节点下的第一个扫描器，多个扫描器 ID 以逗号拼接。
6. **任务类型限制**：`port`（端口扫描）和 `alive`（存活探测）目前仅绿盟扫描器支持。
7. **并发控制**：`ScanTaskSurveyEvent` 的四个查询方法均加了 `synchronized`，高并发场景需注意性能。

## 六、典型调用流程（SOC 对接）

```
1. SOC 调用 outsideSocScan 创建扫描计划
        ↓
2. 系统保存计划并注册到 mint 调度，开始执行扫描
        ↓
3. 扫描完成后，SOC 获取 surveyId（计划实例 ID）
        ↓
4. 按需调用：
   - queryVulnScanResultBySurveyId  → 查漏洞详情（vuln 任务）
   - querySuccessIpsBySurveyId      → 查成功 IP
   - queryFailIpsBySurveyId         → 查失败 IP
   - queryScanPortBySurveyId        → 查端口详情（port 任务）
```
